WYSHUB - Instalador profissional para Windows

Este pacote instala o WYSHUB em:
C:\Program Files\WYSHUB

Ele cria:
- atalho na Area de Trabalho
- atalho no Menu Iniciar

Como instalar:
1. Execute install.cmd como administrador.
2. Aguarde a instalação terminar.
3. Abra o WYSHUB pelo atalho criado.

Requisitos:
- Windows 10 ou 11
- Permissao de administrador
- O aplicativo pode solicitar elevação para acessar sensores e firewall.
