WYSHUB - Instalação para Windows

Este pacote instala o WYSHUB no computador do cliente.

Passos:
1. Execute o arquivo install.ps1 com privilégios de administrador.
2. O programa será instalado em:
   C:\Program Files\WYSHUB
3. Será criado um atalho na área de trabalho e no menu Iniciar.

Requisitos:
- Windows 10 ou 11
- Permissões de administrador
- O app pode pedir elevação para usar sensores e firewall.
