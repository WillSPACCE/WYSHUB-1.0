# WYSHUB v1.0

Bem-vindo à primeira release do WYSHUB.

## O que está incluído

- Versão instalável para Windows
- Versão portátil para uso direto
- Instruções e notas da release

## Downloads

- [WYSHUB_Setup.zip](releases/v1.0/WYSHUB_Setup.zip)
- [WYSHUB_Portable.zip](releases/v1.0/WYSHUB_Portable.zip)

## Como usar

### Instalação
1. Baixe o arquivo WYSHUB_Setup.zip.
2. Extraia a pasta.
3. Execute o script de instalação como administrador.

### Versão portátil
1. Baixe o arquivo WYSHUB_Portable.zip.
2. Extraia a pasta.
3. Execute o executável WYSHUB.exe.

## Observações

- Algumas funções exigem permissão de administrador.
- A leitura de sensores pode variar conforme hardware e drivers.
