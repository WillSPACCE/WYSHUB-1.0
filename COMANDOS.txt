---

# 🔥 ROTINA DIÁRIA (CASA OU TRABALHO)

## 1) Ao começar a trabalhar no projeto

Primeiro sempre baixe as últimas alterações do repositório:

```powershell
git pull
```

Isso garante que você está usando a versão mais atual.

Depois confira se está tudo limpo:

```powershell
git status
```

Se aparecer:

```
nothing to commit, working tree clean
```

Está tudo certo.

---

# 🟢 COMEÇANDO UMA ALTERAÇÃO GRANDE

Antes de mexer em coisas importantes:

Exemplo:

* mudar interface
* mexer em XAML
* trocar sistema de tema
* alterar estrutura do programa
* mexer no instalador

Faça um ponto seguro:

```powershell
git add .
git commit -m "checkpoint antes de alterar interface"
```

Agora você tem uma versão para voltar se algo quebrar.

# 🟣 COMANDOS DO GIT

## Ver alterações

```powershell
git status
```

Mostra arquivos modificados.

---

## Ver exatamente o que mudou

```powershell
git diff
```

Mostra linha por linha o que foi alterado.

---

## Salvar mudanças

```powershell
git add .
git commit -m "mensagem"
```

Cria um ponto de restauração.

---

## Enviar para o servidor

```powershell
git push
```

Manda suas alterações para o repositório.

---

## Baixar alterações

```powershell
git pull
```

Pega alterações feitas em outro computador.

---

## Ver histórico

```powershell
git log --oneline
```

Mostra todos os pontos salvos.

---

# 🆘 SE ALGUMA COISA QUEBRAR

Veja os últimos commits:

```powershell
git log --oneline
```

Copie o código do commit desejado.

Volte:

```powershell
git reset --hard HASH_DO_COMMIT
```

Exemplo:

```powershell
git reset --hard a82f91c
```

O projeto volta exatamente para aquele estado.

# 🟡 BUILD E TESTES

## Baixar dependências

Use quando baixar o projeto em outro computador:

```powershell
dotnet restore
```

---

## Verificar erros de compilação

```powershell
dotnet build SystemWM.sln
```

---

## Limpar arquivos temporários

Quando algo parece estar usando uma versão antiga:

```powershell
dotnet clean SystemWM.sln
```

Depois:

```powershell
dotnet build
```

---

## Executar programa

```powershell
dotnet run --project SystemWM\SystemWM.csproj
```

---

# 🟠 GERAR EXE FINAL

Quando quiser criar a versão para usar em outro PC:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Resultado:

* gera o executável final
* não precisa instalar .NET em outro Windows
* pronto para distribuição
