WYSHUB v1.0

Versao inicial para uso e testes.

Arquivos disponiveis:
- WYSHUB_Setup.zip: instalador automatizado para Windows
- WYSHUB_Portable.zip: versao portatil sem necessidade de instalacao

Como usar:
1. Baixe o arquivo desejado.
2. Extraia a pasta.
3. Execute o arquivo de instalacao ou o executavel do programa.
