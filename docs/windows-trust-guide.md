# Guia de confiança para instalar o WYSHUB no Windows

Quando o Windows mostrar mensagens como "Este app pode ser perigoso" ou "Não foi possível verificar o editor", siga este procedimento:

1. Clique em Mais informações.
2. Se aparecer a opção Executar mesmo assim, escolha essa opção.
3. Se o aplicativo estiver em um local como C:\Program Files\WYSHUB, ele tende a passar mais facilmente no processo de confiança.
4. Para reduzir bloqueios, mantenha o executável na pasta do programa e não em Downloads.
5. Se o Defender bloquear, use o script de exclusões do projeto.

## Recomendação prática
- Instale em: C:\Program Files\WYSHUB
- Execute como administrador somente quando necessário
- Use o atalho criado pelo instalador para abrir o programa
