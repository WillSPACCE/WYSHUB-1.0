SystemWM • WPF + .NET 8

Assistente de suporte técnico para visitas em clientes.

O SystemWM reúne diagnóstico de hardware, controle de firewall, limpeza de máquina, listagem de programas instalados e geração de relatórios prontos para envio por e-mail.
Windows 10/11 Execução com administrador Relatório HTML + Resend Gerar .exe único

Como rodar em 3 passos

  1. Instale o Visual Studio 2022 com .NET Desktop Development ou o SDK .NET 8.
  2. Abra a solução SystemWM.sln e restaure os pacotes NuGet.
  3. Pressione F5 ou publique com dotnet publish para gerar o executável final.

O que o projeto faz

  • Coleta dados completos de CPU, RAM, SSD/HD, GPU e rede.
  • Monitora temperatura, uso e fan do hardware.
  • Controla o Firewall do Windows com regras e status.
  • Faz limpeza de arquivos temporários, cache e lixeira.
  • Lista programas instalados para auditoria rápida.
  • Gera relatório em HTML e envia por e-mail com Resend.

Requisitos

  • Windows 10 ou 11.
  • Visual Studio 2022 ou SDK .NET 8.
  • Permissão de administrador para leitura de sensores e ações no firewall.
  • API Key do Resend para envio de e-mail.

Telas principais

  • Dashboard: visão geral rápida do sistema.
  • Hardware: diagnóstico técnico detalhado.
  • Firewall: ativar, desativar e gerenciar regras.
  • Manutenção: limpeza e listagem de programas.
  • Relatórios: gera o arquivo HTML e envia por e-mail.
  • Configurações: credenciais do Resend e preferências do técnico.

Publicação do executável

  • Gera um único arquivo .exe self-contained.
  • Ideal para levar em pendrive em visitas técnicas.
  • Comando padrão:
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
